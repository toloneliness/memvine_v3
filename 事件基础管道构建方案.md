5.1 MentionBuffer（核心新模块）

Plain Text

数据结构（内存 dict）:
{
  "百年孤独": {
    "mentions": [
      {"ts": 1752510571, "round_id": 2, "context": "我最近读了百年孤独"},
      {"ts": 1752511129, "round_id": 5, "context": "我最近读了百年孤独"},
      {"ts": 1752593219, "round_id": 52, "context": "说到百年孤独"},
    ],
    "entity_type": "book",
    "negated": false,
    "first_seen": 1752510571,
    "distinct_days": 1,        ← 跨不同自然日计数
    "weak_links": ["马尔克斯"],
    "promoted": false           ← 是否已升级为锚点
  },
  "北京": {
    "mentions": [{"ts": ..., "context": "我不在北京"}],
    "negated": true,           ← 被否定，立即标记
    ...
  }
}

方法:
  add(name, entity_type, round_id, ts, context)
  check_promotion(name) → bool        # 检查是否满足升级条件
  negate(name, action)                # 标记否定
  cleanup_expired(max_age_hours=72)   # 清理超时候选
  get_promotable() → list             # 获取所有待升级的实体
  add_weak_link(a, b)                 # 同轮共现 → 弱关联
5.2 TimeResolver（辅助模块）

Plain Text

输入: LLM 提取的 temporal 对象 + 消息时间戳
处理:
  "周三" + 消息时间(周四) → 最近过去的周三 → 2026-07-15
  "下周" + 消息时间 → 下周一 → 2026-07-20
  "明天下午三点" → 明天 15:00 → 2026-07-16T15:00
  "三个月" → duration: 90天
  "上周" → 上周一~周日 → range
  null → 使用消息时间戳

输出: ISO 8601 日期或日期范围
5.3 cortex.py 改造（仅 _ingest_with_semantics）

Plain Text

改造前流程:
  semantic.parse() → EventMolecule → 入图
  event_extractor.extract() → entities → entity_registry.resolve() → 即时入图
                           → facts → 即时连边
                           → temporal → 丢弃

改造后流程:
  unified_extractor.extract(user_msg, ai_msg) → result
    │
    ├── chat 节点入图（保留，存原文 + summary）
    │
    ├── result.is_event == false → return（跳过事件创建）
    │
    ├── result.events[] → 每个事件:
    │     ├── TimeResolver.parse(temporal) → temporal_at
    │     └── event_xxx 节点入图
    │
    ├── result.candidate_entities[] → MentionBuffer.add()
    │     └── check_promotion() → 满足 → entity_xxx 入图
    │
    ├── result.facts[] → 仅当 subj/obj 都是锚点 → 连边
    │
    └── result.corrections[] → MentionBuffer.negate()
