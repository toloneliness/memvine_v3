## 第一步：定义全局唯一时钟 `SystemClock`

新建文件 `core/clock.py`，这是整个系统**唯一允许调用 `time.time()` 或 `pendulum.now()` 的地方**。

```python
# core/clock.py
import time
import pendulum

class SystemClock:
    """
    MemVine 的唯一时间源。

    设计原则：
      1. 内部永远使用 UTC timestamp (float) 进行计算和存储
      2. 只在"人类边界"（LLM prompt、日志）才转换为上海时区
      3. 提供 freeze/advance 接口，让单元测试可以控制时间
    """
    def __init__(self):
        self._frozen_ts: float | None = None

    def now_ts(self) -> float:
        """获取当前 UTC 时间戳 (机器计算/存储用)"""
        return self._frozen_ts if self._frozen_ts is not None else time.time()

    def now_shanghai(self) -> pendulum.DateTime:
        """获取当前上海时间 (仅用于给 LLM 看或日志打印)"""
        return pendulum.from_timestamp(self.now_ts(), tz="Asia/Shanghai")

    # ── 测试控制接口 ──
    def freeze(self, ts: float):
        """冻结时间到指定时间戳"""
        self._frozen_ts = ts

    def unfreeze(self):
        """恢复真实时间"""
        self._frozen_ts = None

    def advance(self, seconds: float):
        """在冻结状态下快进时间"""
        if self._frozen_ts is not None:
            self._frozen_ts += seconds

# 全局单例
clock = SystemClock()
```
