# 🏗️ 优雅重构：Query-Aware Graph Memory Pipeline

## 核心设计哲学

```
你的问题不是"图算法不好"，而是"图算法和检索管道之间存在断层"。

现有架构:
  图算法 ←→ [只用于全局分析/仪表盘] ←→ 与检索无关
  检索管道 ←→ [BFS盲扫] ←→ 不用图算法

优雅架构:
  用户输入 → 意图识别 → 选择图检索策略 → 图算法直接驱动检索 → 整合消解 → LLM
```

**三个核心原则：**

| 原则 | 含义 |
|------|------|
| **图即检索** | 图算法不是分析报告，而是检索引擎本身 |
| **意图即路由** | 不同意图触发不同的图遍历策略 |
| **质量即压缩** | 10条精准记忆 > 100条噪声记忆 |
